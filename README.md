## The story

> She buried him twice. He noticed.

Six words, 33 characters. A complete story: one specific scene (a burial),
an escalation ("twice"), and a final turn ("He noticed") that reframes the
whole line — he was alive, or watching — leaving the reader to fill in the
rest.

`main.py` writes the story to `/output/entry.txt`.

Referral code: `8a2dzbnc`

## How it works

`main.py` writes the story to `/output/entry.txt`. It creates the output
directory first with `os.makedirs`, clears only the contents of the output
directory (never the directory itself), and writes the entry as UTF-8 text.

## Verification

Run `main.py` twice from a clean output directory; `/output/entry.txt` is
byte-identical both times, exactly six words, 33 characters, valid UTF-8,
and non-whitespace — inside the gate (1–60 characters).
